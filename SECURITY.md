# Security Policy / セキュリティ

Aliator CashRegister is a **Java portfolio demo**, not a production-certified payment/POS system.

Never commit real production credentials, SMTP/DeepL/Google keys, database passwords, JWT/OTP secrets, Raspberry Pi printer bearer tokens, customer or tenant data, private backups, receipts with personal information, or operational logs.

For security issues, contact the project maintainer privately instead of publishing exploit details or credentials in issues.

Real-money payment processing, PayPay integration, legal tax receipt/Qualified Invoice compliance and allergen accuracy are outside the verified scope of this demo.

**日本語:** 本番環境の認証情報、APIキー、印刷用トークン、顧客データおよびバックアップを公開しないでください。このアプリケーションは実際の決済や法令準拠を保証しない技術デモです。
